# обход 1.0.0

Первый выпуск: запрет, прокси для Telegram и VPN в одной программе.

## Что внутри

- **Запрет.** Автоматический подбор стратегии с запоминанием удачной, 34 стратегии (штатные Flowseal и авторские DAVL), тесты TLS 1.2, TLS 1.3 и «заморозки» на 16–20 КБ, список сервисов с логотипами, свои домены, игровой фильтр.
- **Картинки Discord.** Если провайдер блокирует сервер картинок по IP, программа сама находит рабочий адрес и прописывает его в `hosts`.
- **Telegram.** Прокси tg-ws-proxy включается одной кнопкой и добавляется в Telegram ссылкой.
- **VPN.** Ссылки и подписки как в Happ и Incy: VLESS (Reality, XHTTP), VMess, Trojan, Shadowsocks. Режимы «системный прокси» и «весь трафик (TUN)», российские сайты напрямую, пинг, лимит устройств (HWID).
- **DNS.** Окно с популярными DNS-серверами (Cloudflare, Google, Quad9, AdGuard, Comss, Яндекс и др.), их пингом и применением в один клик, с возвратом к DNS провайдера.
- **Обновления.** Запрет, прокси и ядра VPN обновляются с GitHub прямо из программы.
- **Интерфейс.** Тёмная тема «жидкое стекло» (графит и чёрная), работа из трея, автозапуск с Windows.
- **Установщик.** Около 3 МБ, пошаговый, с объяснением про антивирус и инструкцией для картинок Discord.

## Установка

Скачайте `obhod-setup.exe` ниже и запустите. Нужны права администратора и интернет: при необходимости докачаются .NET 10 и прокси для Telegram.

Защитник Windows может ругаться на программу, это ложное срабатывание. Что делать, написано в [README](../README.md#антивирус-ругается--что-делать).
